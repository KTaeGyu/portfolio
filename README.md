# Portfolio

목표: 경력 약 1.5년 동안의 개발·운영 경험을 문제 해결 중심으로 설명합니다.

계획 스택: React, TypeScript, Vite, Tailwind CSS, React Router. 배포 목표: Vercel.
현재는 폴더와 콘텐츠 기획만 구성한 상태이며 실행 가능한 웹 앱은 아직 없습니다.

- docs/site-plan.md: 페이지 구성과 작성 기준
- docs/projects/: 공개할 프로젝트별 기술 스토리
- public/: 향후 공개 가능한 이미지와 정적 파일

사내 소스, 실제 데이터, 내부 화면과 민감정보를 포함하지 않습니다. 직접 작성한 아키텍처와 데이터 흐름 다이어그램으로 설명합니다.
